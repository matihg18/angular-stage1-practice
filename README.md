The objective was building that app using Angular in order to put into practice the concepts seen in the class. To achieve that, i created the NgModules and  the Components that were 
required using property bindings to communicate the parents with their child, i wrote the templates that would build the page using interpolation to access the objects attributes, attribute
directives to manipulate the appearance of some DOM elements, structural directives to iterate in the post's list, and pipes to format the date, and i also wrote the CSS to style the component
templates.
